Передайте цей файл разом із завданням «приведи цей артефакт до дизайн-системи FEEL Again». Нижче — жорсткі правила палітри, семантики, типографіки та поверхонь. Дотримання обовʼязкове.

PRIME DIRECTIVE
Колір = сенс, не декор

Кожен колір несе значення. Ніколи не призначайте колір «бо гарно». Поверхня позначає тип сторінки та роль користувача; акцент позначає стан (спокій / тиск / тривога / головне). Шрифти й кнопки в усій екосистемі — однакові, щоб їх легко впізнавати; різниться лише поверхня.

01 · Палітра та семантика
0B2422 → 3E91A2
Teal / Petrol — спроможність

Ресурси, благородство, впевненість, сталість. Домінанта (~55%). Темна тема й сині поверхні. Тон глибокий і приглушений — як у Bunker; уникайте надто світлого блакитного.

8A3410 → F08A2E
Orange — операційність

Рух, потреба, тиск, загроза, подвійність (~25%). Існує лише у звʼязці з teal — це його сенс. Orange без teal не буває.

C8901A → FCE9B0
Gold — головне

Колір, що поглинає всі інші, навіть світло. Тільки для головного: підсумок, ROI, очищення, статус-кво, фасад що відмітає тривоги. Теплий орендж-золотий (як заставка з пазлами). Рідко, але владно.

тривога ≠ gold
Yellow — тривога / відхилення

Чистий жовтий читається як тривога й відхилення від плану — НЕ як «головне». Не плутати з gold. Не призначати ролі/користувачу.

Signal red
Критичні алерти. <2%.
Cream / sand
Світла тема — оповідь, спокій.
02 · Градієнт = потужність і стик
Стик інтересів = пожежа

Teal→orange у лоб — розрив (GAP) між потребою і спроможністю. Привертає увагу.

Обʼєднання зусиль

Плавний перехід teal→gold — синергія, спільний результат. Використовувати свідомо.

Правило: градієнт — інструмент сенсу (потужність / стик / обʼєднання), а не фон сторінки. Монокольорові частини діаграм лишаються монокольоровими; градієнт — лише там, де є що показати.

03 · Типографіка
Заголовки
OSWALD / ARCHIVO — подовжені, високі літери. Завжди в плашці з кантом, що починається з однієї літери й обходить текст.
3.9M
A-417 · DLI-02
ЦИФРИ — легке накреслення (300–400), не жирні. Лейбли — Spline Mono. Тіло — Source Sans 3 (≥16px, яскравість ≥90%).
  • Колір заголовка прив'язаний до кольору поверхні (як у Bunker): на teal — gold/cream; на sand — petrol; на orange — cream.
  • Другорядні (не головні) заголовки можна робити двоколірними/градієнтними для виділення ефекту — головні назви ні.
  • Жодного рукописного шрифту. Жодних emoji поза прапором 🇺🇦 у футері.

дашборд, кабінети
Сітка / пазл
функціональні стор.

Сітка зʼявляється на функціональних сторінках (реєстрація → кабінети) — відрізняє «дію» від «оповіді». Насічка: прямокутна, ромбова (45°) або пазлова (ледь помітна) на сторінках, де ставиться діагноз / розкривається проблема — гуманітарно-клінічний пазл.

05 · Чек-ліст конверсії артефакту
✔ Робити
  • Перемалювати поверхні під тип сторінки (світла оповідь / темна дія).
  • Призначити акценти за станом (teal спокій, orange тиск, red критично).
  • Кнопки й шрифти — єдині по всій екосистемі.
  • Заголовки — у плашках з кантом, колір під поверхню.
  • Цифри — легке накреслення; лейбли — mono.
  • Сітка на функціональних сторінках.
  • Логотипи партнерів — нормалізувати: один тон, рівна оптична висота, рівні відступи.
✘ Не робити
  • Не призначати колір кнопок/шрифтів за роллю — лише поверхню.
  • Не плутати yellow (тривога) з gold (головне).
  • Не лити градієнт як фон сторінки.
  • Не використовувати надто світлий блакитний.
  • Жодних крапок-у-крузі, дешевих іконок, рукописних шрифтів.
  • Не центрувати різнокольорові логотипи різного розміру.
  • Не зміщувати літери логотипа по горизонталі довільно.
