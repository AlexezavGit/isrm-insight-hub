# Tailored capability configuration and unobstructed guidance

**Goal:** Let ISRM describe and negotiate a tailored solution while keeping the member-use prototype distinct and legible.

**Design decisions:** Configuration uses the existing right inspection dock: three adjacent panels: a compact text tree, a workflow description and a service description. Both close independently; the remaining panel occupies the edge. Widening the tree exposes package composition controls; widening the description exposes dependencies, candidate integrations and technology. Core and optional package changes persist into scope and exports, and changed packages retain indicative reference amounts and are explicitly marked for reassessment in the detailed proposal. Preset prices remain reference prices only. The configurator's audience coverage is an explicitly illustrative many-to-many demonstration, never an assertion about actual member activity.

**Alternatives:** Leaving the tree on the far left preserves the current separation but adds travel and inconsistent panel behaviour. An unrestricted graph editor is excessive for a proposal conversation. Reusing the adjacent inspection dock provides continuity with the accepted dossier/list interaction and preserves a working graph area.

**Guidance:** Replace the large fixed coach with a compact movable-by-placement coach that avoids the current target. Dim the rest of the workspace through a non-interactive spotlight; preserve pause, close and take-over. Increase primary touch targets and graph node hit areas without increasing every node's visible size.

**Narrative:** Retain the agreed six-slide argument. Apply one-glance visuals without fabricated funnel yields, legal immunity, accepted delivery stages or monetary returns. Show shared-record connection paths distinctly from personal introductions. Logo leads to scope as requested; four navigation stages remain explicit and gain compact previous/next wrapping controls on mobile.

**Integration and architecture:** Present an integration-led solution with monochrome labelled integration candidates and their agreement status. Create a private architect clarification/addendum comparing existing-platform, adapted-frontend and custom choices. Existing 640 hours, 96 OSINT adapter hours and site prices remain assumptions, not accepted quotes. Do not double-count QA or silently replace the approved workbook.
