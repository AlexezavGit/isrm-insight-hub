# Довідкові матеріали

Відібрані копії з початкової теки проєкту. Походження та контрольні суми записані в `source-manifest.json`. Оригінали залишилися на місці.

- `4_ISRM_Content_to_Service_Assessment.md` — матеріал для наступної перевірки прив’язки сервісів до контенту ISRM.
- `5_ISRM_Expert_Registry_Access_Contract.md` — чернетка правил доступу; не чинний договір і не реалізована авторизація.
- `ISRM_Website_Audit_EN.docx` — довідка для звіряння наративів із сайтом замовника; актуальність окремих сторінок потрібно перевіряти перед використанням.

Нумеровані старі архітектурні та цінові документи, попередні кошториси, агентські налаштування й сирі CRM-файли не дублювалися сюди. Чинні клієнтські документи — у `../../public/`, поточний партнерський кошторис — у `../partner-review/`.
