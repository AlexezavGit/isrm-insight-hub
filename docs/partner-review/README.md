# Для обговорення з Алексом і Дмитром

Чинний розрахунок: [ISRM_Partner_Pricing_Review.xlsx](ISRM_Partner_Pricing_Review.xlsx), англійською мовою.

Вісім аркушів: Comparison, Current Development, Assumptions, Development, Executors, Internal Settlement, OSINT and Operations, Repository Review.

Ціна покриває розробку, повну оцінену вартість виконавчих функцій, операційні ліміти та окремий прибуток. 30% нижче UK — ціль для порівняння, не обмеження собівартості. Припущення про надбавку15% до повних витрат редагується. Відхилення від UK рахується від запропонованої забезпеченої ціни.

172години — середина оцінки відтворення поточного демо. Це не виміряний час і не оцінка всієї місячної роботи у всіх гілках. Окремий Repository Review описує знайдені історичні результати без повторної оплати спільного коду. Походження звірки: `git-branch-audit-20261028.json`.

Попередні640годин залишено планом майбутньої production-розробки до технічного підтвердження reuse. Оплату створеної частини забезпечено всередині збільшеної статті розробки й віднято один раз, щоб показати залишок розробникам. У Internal Settlement цієї оплати немає.

Функціональні гонорари — оцінки за публічними ринковими орієнтирами, а не погоджені особисті ставки. OSINT використовує медіану; юридична ставка є прикладом одного провайдера, не середнім усього ринку. Прямі операційні суми — планові ліміти, не отримані котировки. Прибуток і виплати показані до податків.

Для зовнішньої оцінки підготовлено [окремий пакет розробникам](../developer-review/README.md), без внутрішніх гонорарів та прибутку. Ціни на опублікованому сайті ще не змінені.
