# Для обговорення з Алексом і Дмитром

Чинний розрахунок: [ISRM_Partner_Pricing_Review.xlsx](ISRM_Partner_Pricing_Review.xlsx).

Шість аркушів: порівняння, поточна розробка, припущення, розробка, партнери, OSINT та операції. Поточна розробка оцінюється окремо як вартість відтворення, а не вигаданий облік фактично відпрацьованих годин. Компенсацію вже створеного графа партнери погоджують окремо; повторно включати ті самі роботи до нового бюджету не слід.

Порожні гонорари й операційні витрати не є нульовими витратами. Залишок за сценарієм ще не є прибутком до розподілу. Публічні ціни — окрема індикативна база для обговорення scope, не затверджений договір.
