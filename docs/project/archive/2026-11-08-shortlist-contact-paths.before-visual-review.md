# Контрольна точка: мапа шляхів контактів у shortlist

**Дата:** 2026-11-08  
**Статус:** виконано для локальної демонстрації; не є production-контактом або підтвердженням фактичного зв’язку.

## Рішення користувача

Shortlist має показувати не просто збережені профілі, а мапу контактів і можливостей користувача: прямі контакти першого рівня та, де є підстава, опосередковані шляхи через контакти першого рівня. До цієї мапи повинні вести пошук за експертизою та людьми.

Для демонстрації користувач уточнив два допустимі варіанти маршруту: підготувати безпечний прямий контакт або попросити рекомендацію через лідера спеціалізації, практики чи регіонального представника. Спільна експертиза сама по собі не доводить особисте знайомство.

## Реалізація

- У shortlist додані дії для підготовки прямого контакту та запиту рекомендації через одну з трьох неперсоніфікованих ролей.
- Карта показує маршрут `Ви → фахівець` або `Ви → роль посередника → фахівець`; підготовлений маршрут відокремлений від позначки користувача, що комунікацію вже розпочато.
- Демонстраційний стан зберігається локально у браузері. Повідомлення не надсилається, контактні дані не передаються, роль посередника не представлена як конкретна призначена особа.
- Третій рівень маршруту не реалізовано: доступні дані не підтверджують ланцюги персональних контактів. Не можна називати такий маршрут реальним знайомством або рекомендацією.
- У walkthrough стан тимчасовий; робочі дії не повинні створювати враження спільної production-бази.

## Змінені файли

- `src/components/NetworkShortlist.tsx` — дії та відображення контактного маршруту, стани підготовки й комунікації.
- `src/lib/contact-paths.ts` — типізована локальна модель, читання, збереження та валідація маршрутів.
- `src/lib/contact-paths.test.ts` — перевірки збереження, вилучення та відхилення некоректних даних.
- `src/styles.css` — стилі карти маршрутів та допоміжного тексту.

## Перевірка та обмеження

- П’ять цільових тестів для контактних шляхів і збережених shortlist пройшли.
- ESLint для змінених TS/TSX-файлів пройшов без помилок.
- `npm run build` успішний; у збірці залишилися попередження про Vite-конфігурацію, застарілий `inputValidator` і великий client chunk.
- У локальному браузері перевірено відображення прямого маршруту та маршруту через регіональну роль. Спроба зняти надійний скриншот завершилася білою сторінкою або тайм-аутом, тому перевірку візуальної якості на desktop і mobile не вважати завершеною.
- Перевірка `impeccable detect` повернула попередження про наявні правила шрифтів та акцентних смуг у `src/styles.css`; окремих знахідок для нових маршрутів не виявлено. Код завершення 2 означає, що детектор не пройшов повністю.
- Тестові позначки в browser storage прибрані; початковий shortlist лишився без змін.
