## Відхилені непідтверджені твердження

У перевірених runtime-шляхах локальної копії й опублікованого коміту не знайдено iso-orchestrator, discoverProjectSessions, sessionGraph або batch-state.tsv та їхнього зв’язку з досьє ISRM. Готовність AI-досліджень із цього не підтверджено. Граф сесій агента не є доказом професійних зв’язків людей або верифікації. Окремий інструмент в іншому репозиторії не виключається цим висновком.

`serviceCovers` у network-model.ts призначає ілюстративні сервісні зв’язки за хешем коду профілю. Це не зацікавленість, згода чи попит. Не переносити такі призначення в майбутній результат вивчення потреб. Код цієї моделі в поточному пакеті не змінений. Не заявляти суверенність, конверсію в платне членство, юридичну достатність або готовність до промислової експлуатації без окремих доказів.
